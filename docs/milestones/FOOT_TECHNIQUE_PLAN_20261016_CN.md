# 脚法（触球技术）学习计划

日期：2026-10-16

状态：当前主线计划的核心部分。接口定义见[统一技能接口 v1](SKILL_INTERFACE_V1_PLAN_20261016_CN.md)，
总目标、硬约束和资产见[主计划](SOCCER_SKILLS_RESEARCH_PLAN_20261014_CN.md)。本文回答一个问题：
**机器人怎么知道用脚的哪个位置、以什么方式触球。**

## 0. 原则

触球动作最终由 RL 学，但"用哪里触球"不能只靠出球结果去碰运气。每一种脚法都必须同时有三样监督：

| 监督 | 作用 | 没有它会怎样 |
| --- | --- | --- |
| 显式定义 | 用几何量把脚法写清楚：哪只脚、脚板哪个区域、碰球的哪个点、脚以什么方向撞过去 | 脚法只是名字，无法评测 |
| 参考动作（教师 reference） | 触球那一刻，参考里指定的区域正好落在球上指定的点，法向和摆动方向都对 | RL 从错误的起点出发，常收敛到"小腿压球"之类的捷径（S0 已观察到） |
| 显式奖励 | 接近时引导区域对准接触点；触球时检查区域、法向、球上触点、撞击方向；之后检查出球结果 | 参考只是软约束，触球附近的跟踪又被屏蔽，没有奖励就不能保证真的用对区域 |

S0 的结论说明了为什么三样都要：现有射门的触球区域完全由参考的整体动作风格决定（同一参考 5 个 seed 落在同一区域），
奖励里没有区域约束，于是 44/55 脚有小腿参与触球。

## 1. 脚法的显式定义（脚法规格）

每种脚法用一张规格卡描述。字段全部是可测量的几何量，脚坐标系为 `*_ankle_roll_link`（x 前、y 左、z 上）：

| 字段 | 含义 |
| --- | --- |
| 脚 | 左或右 |
| 区域 | 接口 v1 的 7 个脚板区域之一（前端、前内角、内侧、前外角、外侧、脚面、脚底） |
| 区域触点 | 区域内的具体点（脚坐标），默认取区域中心 |
| 区域法向 | 触球瞬间该区域朝外的法向，必须与"期望冲量方向"对齐 |
| 球上触点 | 球面上的接触点，用高度（−1 到 1）和水平偏置（左右）表示；高度低于 0 让球离地 |
| 期望冲量方向 | 出球方向加仰角；射门由球门决定，传球由队友决定，盘带由规划层决定 |
| 撞击速度方向 | 触球前区域点的速度方向（脚坐标）；区分"推"（沿法向）与"抽"（带切向分量） |
| 踝状态 | 触球时踝 pitch、roll 的目标范围（如正脚背需要踝下压锁定） |
| 允许接触的其他部位 | 默认不允许；小腿、膝等触球计为违规 |
| 期望结果 | 球速档、仰角范围；弧线不评（仿真无马格努斯力） |

第一版规格（数值在 T0 用数据和 S0 方法校准后冻结）：

| 技能 | 脚法 | 区域 | 球上触点高度 | 撞击方向 | 踝状态 | 期望结果 |
| --- | --- | --- | ---: | --- | --- | --- |
| 射门 | 内脚背抽射 | 前内角 | −0.3 | 沿法向，略向上 | 外翻、锁定 | 全力，仰角 10–25° |
| 射门 | 正脚背抽射 | 脚面 | −0.2 | 沿法向（脚面朝前） | 下压到底、锁定 | 全力，仰角 5–20° |
| 射门 | 脚弓推射 | 内侧 | 0 | 沿法向 | 中立 | 中速，低平 |
| 射门 | 外脚背射门 | 前外角 | −0.2 | 沿法向 | 内翻 | 全力 |
| 射门 | 脚尖捅射 | 前端 | 0 | 沿 x | 中立、锁定 | 快速出脚，中高速 |
| 传球 | 脚弓传球 | 内侧 | 0 | 沿法向 | 中立 | 到达目标，地滚 |
| 传球 | 正脚背平抽 | 脚面 | 0 | 沿法向 | 下压锁定 | 到达远目标，低平 |
| 传球 | 内脚背长传、脚尖挑传 | 前内角、前端 | −0.6 | 由下向上 | — | 离地（后期） |
| 盘带 | 推球 | 前端或内侧 | 0 | 沿行进方向 | 中立 | 球到下一次可及处 |
| 盘带 | 扣球 | 前内角 | 0 | 横向向内 | 外翻 | 变向 |
| 盘带 | 拨球 | 外侧 | 0 | 横向向外 | 内翻 | 变向 |
| 盘带 | 踩球、拉球 | 脚底 | +0.6 | 向下、向后 | 背屈 | 停球或回拉 |

S0 实测的现有射门（作为第一张规格卡的起点）：前内角或脚面，触点高度 −0.53，仰角约 23°，8.45 m/s，但有小腿参与。

## 2. 参考动作：触球感知的参考修正

现有参考来自视频重定向，触球那一刻脚的哪一部分碰球是"碰巧的"。做法是保留全身风格，只在触球窗口内修正腿：

1. **定接触点。** 按规格卡，在球上取接触点 c = 球心 + R·(球上触点方向)，期望冲量方向 d。
2. **腿部逆运动学。** 在 `kick_frame` 解右腿 6 个关节（髋 3、膝 1、踝 2）：区域触点到达 c，区域法向对准 d，
   并尽量接近原参考（加权最小二乘）。踝的 pitch、roll 由这一步给出，不用视频里的脚踝。
3. **撞击速度。** 在 `kick_frame` 前 3–5 帧约束区域点的速度方向等于规格卡的撞击方向，速度大小沿用原参考。
4. **平滑接回。** 在窗口 [kick_frame − 15, kick_frame + 10] 内，用平滑权重从原参考过渡到修正值再过渡回去；窗口外不变。
5. **运动学检查。** 修正后逐帧检查：触球帧区域到球面的距离 < 1 cm；除指定区域外，腿上其他碰撞体（小腿、膝）与球的最近距离 > 2 cm；
   支撑脚不滑动；关节在限位内。
6. **输出。** 修正后的参考写回 npz，并在 Contact Graph 里给每个触球附上规格卡字段（区域、球上触点、冲量方向），供奖励和事件编码使用。

同一个参考可以用不同规格卡修正，得到同一套全身动作下的多种脚法。这是脚法数据的主要来源：真正要从视频补的，
只是"动作风格明显不同"的脚法（例如脚弓推射和抽射的摆腿幅度差别很大）。

## 3. 显式奖励

所有项都以规格卡为准，在接口 v1 的奖励模板（接口文档 2.6）上细化。触点测量：Isaac 中按球心到脚板几何（区域盒）的最近点求实际触点，
MuJoCo 中直接读接触点；两边用同一个分类函数 `skill_event.classify_contact`。

| 阶段 | 奖励项 | 定义 |
| --- | --- | --- |
| 接近 | 区域对准 | 规格区域中心到球上接触点的距离，exp(−d²/σ²)，只在接近阶段末段（软相位进度 > 0.5）生效 |
| 接近 | 法向预对准 | 规格区域法向与期望冲量方向夹角的余弦 |
| 接近 | 撞击方向 | 区域点速度方向与规格撞击方向的余弦，乘以速度大小的饱和项 |
| 触球 | 区域命中 | 实际触点分类等于规格区域得满分；否则按实际触点到规格区域中心的距离给部分分 |
| 触球 | 球上触点 | 实际球上触点高度与规格的误差 |
| 触球 | 法向 | 实际受力方向（作用在球上的力）与期望冲量方向的夹角 |
| 触球 | 违规接触 | 小腿、膝或另一只脚碰球：按其冲量占比扣分 |
| 出球 | 结果 | 全力模式：不饱和球速 + 方向 + 仰角范围；到达模式：到达误差 |
| 全程 | 跟踪 | 跟踪修正后的参考；触球窗口内腿部跟踪不再整段屏蔽，而是只屏蔽踝（踝由区域和法向奖励决定） |

## 4. 教师与学生

- **教师 = 脚法条件的跟踪策略。** 从 s859 出发，观测加上当前触球事件（接口 v1 的 13 维，含区域和球上触点），
  在"修正参考 + 脚法奖励"下续训。每回合按规格卡采样脚法，参考取对应修正版本。球速奖励不饱和（P0 力量臂已证明）。
- **学生 = latent 学生。** 教师过关后，按 S1 的路线 A 蒸馏到共享网络（`soccer/latent/latent_skill_net.py`），事件作为显式输入，
  参考只给编码器。学生先验模式下也必须保持各脚法的区域命中率。
- **盘带用同一套。** 区域标签来自 `dribble_cg_surface`（0 内侧、1 外侧），规格卡用第 1 节盘带行；支线没有教师，直接在 Stage 1′/2′ 里用这些奖励。

## 7. 风险

- 修正参考后动作可能不自然或不可执行：T1 的回放命中率门槛先过滤，过不了的规格卡说明这条参考的全身动作不支持该脚法，需要换参考。
- 加区域约束后球速可能下降（现在的高速部分来自小腿压球）：T3 对主射门脚法保留 8.07 m/s 硬门槛；若所有合规脚法都达不到，
  需要回到用户决定是放宽"小腿不得触球"还是接受较低球速。
- 真机脚面加护垫后几何和刚度变化：S0b 的碰撞体按护垫后外形做，刚度用接触参数近似，真机测试时再校准。
